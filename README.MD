# 🎮 SimuladorEmprende

¡Bienvenido a **SimuladorEmprende**!  
Este proyecto es un *minijuego educativo* desarrollado como **proyecto de grado** en diciembre de 2019 dentro del semillero **Ayni** de la Universidad *Unicatólica*.  
Su propósito es ayudar a los usuarios a entender, de forma dinámica e interactiva, **cómo formar y gestionar una empresa** desde cero.

---

## 📌 Descripción

**SimuladorEmprende** es un simulador tipo juego en el que, a través de decisiones y acciones, el jugador asume el rol de un emprendedor y experimenta el proceso de crear, administrar y hacer crecer una empresa.  
Es especialmente útil para estudiantes o personas interesadas en emprendimiento y negocios. :contentReference[oaicite:1]{index=1}

---

## 📋 Características

✨ Características principales del proyecto:

- Simulación de decisiones empresariales
- Interfaz tipo juego (minijuego educativo)
- Incluye sonido, gráficos y mecánicas de juego
- Pensado para enseñar lógica básica de emprendimiento
